# Constants (Константы)

## Что такое константа?

Константа — это значение, которое нельзя изменить после создания.

Используется для данных, которые всегда одинаковые.

Например:

- число π;
- количество дней в неделе;
- максимальный размер сообщения.

---

## Объявление

```go
const Pi = 3.14159
```

---

## Несколько констант

```go
const (
    MaxUsers = 100
    Version = "1.0"
    Debug = true
)
```

---

## Изменить нельзя

```go
const Age = 22

Age = 23
```

Ошибка компиляции.

---

## Почему использовать const?

Если значение никогда не изменится, лучше использовать константу.

Это:

- безопаснее;
- понятнее;
- помогает избежать ошибок.

---

## Частые ошибки

### ❌ Пытаться изменить const

```go
const Max = 10

Max = 20
```

Ошибка.

---

### ❌ Использовать переменную как const

```go
x := 10

const Value = x
```

Так нельзя.

Константа должна быть известна во время компиляции.

---

## Что важно помнить

✅ const нельзя изменить.

✅ const известна во время компиляции.

✅ Используй const для фиксированных значений.

---

## Проверь себя

Что произойдет?

```go
const Version = "1.0"

Version = "2.0"
```

Ответ

Ошибка компиляции.

## Вопрос с собеседования

**Когда использовать const вместо var?**

Ответ:

Когда значение никогда не должно изменяться во время работы программы.
