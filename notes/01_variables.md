# Variables (Переменные)

## Что такое переменная?

Переменная — это именованная область памяти, в которой хранится значение.

Значение можно изменять во время выполнения программы.

---

## Объявление

### Полная запись

```go
var age int = 22
```

---

### Go сам определяет тип

```go
var age = 22
```

Тип будет:

```text
int
```

---

### Короткое объявление

Используется чаще всего.

```go
age := 22
```

Работает только внутри функций.

---

## Изменение значения

```go
age := 22

age = 23
```

---

## Несколько переменных

```go
name := "Lisa"
age := 22
salary := 1500.50
```

или

```go
var (
    name string
    age int
    active bool
)
```

---

## Нулевые значения (Zero Values)

Если переменной ничего не присвоить, Go сам задаст значение.

| Тип | Значение |
|------|----------|
| int | 0 |
| float64 | 0 |
| bool | false |
| string | "" |
| pointer | nil |

Пример

```go
var age int

fmt.Println(age)
```

Вывод

```
0
```

---

## Когда использовать :=

Используй `:=`, если:

- создаешь новую переменную;
- находишься внутри функции.

```go
func main() {
    name := "Lisa"
}
```

---

## Когда использовать var

Используй `var`, если:

- нужна переменная на уровне пакета;
- хочешь явно указать тип;
- хочешь получить zero value.

```go
var version string
```

---

## Частые ошибки

### ❌ Использовать := второй раз

```go
age := 22
age := 23
```

Ошибка.

Правильно

```go
age := 22
age = 23
```

---

### ❌ Использовать := вне функции

```go
name := "Lisa"
```

Ошибка.

Нужно

```go
var name = "Lisa"
```

---

## Что важно помнить

✅ `:=` создает новую переменную.

✅ `=` изменяет существующую.

✅ `:=` работает только внутри функций.

---

## Проверь себя

Что выведет программа?

```go
func main() {
    age := 22
    age = 30

    fmt.Println(age)
}
```

Ответ

```
30
```

---

## Вопрос с собеседования

**Чем отличается `=` от `:=`?**

Ответ:

`:=` одновременно объявляет и инициализирует новую переменную.

`=` только изменяет значение уже существующей переменной.
